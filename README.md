# 2627_ESE_Projet_Inhibot
_Projet réalisé par SERPHIN Bradley, NAVIZET Léonard et BOISBOURDIN Lucas_

---
## Présentation du projet
Le but du projet est de créer un petit robot autonome capable de récupérer des canettes en fonction de leur couleur, par exemple rouge ou verte, et de déposer ces canettes dans une zone définis à l'avance.
